# Досье CoreProtect

Руководство для персонала Minecraft-серверов, которые используют [CoreProtect](https://docs.coreprotect.net/).

**Сайт:** https://magomedovex-code.github.io/coreprotect-casebook/

## Что внутри

- **Разбор дела:** игрока убивают, лут прячут в закопанном сундуке, а часть вещей дюпают. Десять шагов: найти место смерти, проследить лут, доказать дюп, очистить тайник и вернуть вещи, не откатив ничего у других игроков. Впишите своего подозреваемого, жертву и окно времени, и все команды обновятся.
- **Быстрый режим:** всё дело в виде чек-листа с кнопками копирования и привычки, которые ускоряют расследования в игре.
- **Лаборатория радиуса:** анимированная карта показывает, до чего дотягивается откат при разных `u:`, `r:` и `a:`.
- **Конструктор команд:** собирает команду `/co`, объясняет её простыми словами и предупреждает, если она захватывает лишнее.
- **Справочник:** все команды `/co`, все параметры, все 22 действия, правила очистки, перенос базы данных и права.

## Главные правила

1. Сначала запустите параметры как `/co lookup`, потом замените `l` на `rb`.
2. В каждом откате указаны кто (`u:`), когда (`t:`) и где (`r:`).
3. Сначала уберите лут из тайника вора, потом возвращайте его жертве.
4. `/co undo` отменяет откат или восстановление.

## Примечания

- Собрано по официальным страницам [commands](https://docs.coreprotect.net/commands/) и [permissions](https://docs.coreprotect.net/permissions/).
- Пример вывода в чате условный. Формулировки зависят от версии CoreProtect.
- Независимое руководство. Не связано с CoreProtect.

Это один файл `index.html` без сборки. Чтобы пользоваться им локально, откройте его в браузере.
